# Reptro

Простой дневник тренировок: подходы, вес, повторения и сравнение результатов.

Статический сайт без сборки: HTML, CSS и JavaScript. Авторизация — Firebase Auth. Пароли и данные аккаунтов не хранятся в репозитории. `firebase-config.js` содержит публичную конфигурацию веб-приложения Firebase.

## Данные

Тренировки сохраняются в localStorage браузера отдельно для каждого Firebase UID. Синхронизация между устройствами пока не реализована. Очистка данных браузера удаляет локальные тренировки.

## Запуск

```sh
python3 -m http.server 5173
```

## Публикация

GitHub Pages: ветка `main`, папка `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll. Домен `reptro.ru` указан в `CNAME`. Для работы домена нужно направить DNS на GitHub Pages и включить HTTPS в настройках репозитория.

Программа тренировок настраивается в `workout-program.json`.
